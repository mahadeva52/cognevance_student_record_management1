# Student Record Management System

## Objective
A menu-driven Python application for adding, updating, deleting, searching and reporting student records.

## Technologies
- Python 3
- CSV file handling
- Functions and exception handling

## Run
```bash
python main.py
```

## Features
1. Add student
2. Update student
3. Delete student
4. Search student
5. View all students
6. Performance report
7. Input validation and exception handling
