# Project Report – Student Record Management System

## 1. Introduction
This project implements a simple student record management application using Python.

## 2. Objectives
- Manage student records.
- Practice file handling.
- Apply functions and modular programming.
- Validate inputs and handle errors.
- Produce a student performance report.

## 3. Modules
- CSV file handling
- CRUD operations
- Search
- Validation
- Reporting

## 4. Workflow
User → Menu → CRUD/Report operation → CSV file → Result

## 5. Testing
Test add, update, delete, search, invalid age/marks, empty data and duplicate IDs.

## 6. Conclusion
The project demonstrates fundamental Python programming and file-handling skills.
